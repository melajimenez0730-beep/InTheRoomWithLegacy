# Parenting a Parent: A Guide for Adult Children
## Professional PDF Document Specification

### Document Overview
This document provides comprehensive specifications for creating a professional, multi-page PDF document using the content from "Parenting a Parent: A Guide for Adult Children" guide. The design adheres to the brand palette with Primary Deep Blue (#052d3f) and Warm Brown Accent (#a57c52) while avoiding yellow.

### Document Specifications
- Format: PDF (8.5" x 11", portrait orientation)
- Pages: 16 (including cover and back page)
- Color Profile: CMYK for print production
- Resolution: 300 DPI for all images
- Bleed: 0.125" on all sides for printed version

### Brand Elements
- Primary Deep Blue: #052d3f (CMYK: 100, 70, 40, 50)
- Warm Brown Accent: #a57c52 (CMYK: 25, 50, 70, 20)
- Body Text: Dark Gray #333333 (CMYK: 0, 0, 0, 80)
- Background: White #ffffff
- Tip Box Background: Ultra-Pale Gray #f8f8f8 (CMYK: 0, 0, 0, 3)
- Logo: "In the Room with Legacy™" (white version for cover and back page)

### Typography System
- Headings: Garamond (or similar serif font)
  - Section Headers: 24pt, Deep Blue, bold
  - Subsection Headers: 18pt, Deep Blue, bold
- Body Text: Open Sans (or similar sans-serif font)
  - Size: 11pt
  - Color: Dark Gray
  - Line spacing: 1.5
- Pull Quotes: Garamond Italic, 14pt, Deep Blue
- Lists: 11pt Open Sans with Warm Brown bullets

### Production Notes
- All images should be high-resolution (300 DPI minimum)
- The guide should be exported as both:
  1. Print-ready PDF with CMYK color profile and bleeds
  2. Digital-optimized PDF with RGB color profile and hyperlinked CTAs
- For digital version, all CTA buttons should be hyperlinked to relevant pages
- Consider adding subtle page transitions for digital version
- Ensure accessibility features are implemented (proper tagging, alt text for images)
- Final file should be optimized for both print and digital distribution
