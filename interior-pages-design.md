# Interior Pages Design

## Global Layout Elements
- Margins: 1" on all sides
- Header area: 1.5" from top
- Footer area: 0.75" from bottom
- Page numbers: Centered in footer area
- Running header: Section title in Deep Blue (#052d3f), right-aligned

## Typography System
- Section Headers:
  - Font: Serif font (Garamond or similar)
  - Size: 24pt
  - Color: Deep Blue (#052d3f)
  - Weight: Bold
  - Spacing: 12pt space after

- Subsection Headers:
  - Font: Serif font (Garamond or similar)
  - Size: 18pt
  - Color: Deep Blue (#052d3f)
  - Weight: Bold
  - Spacing: 8pt space after

- Body Text:
  - Font: Sans-serif font (Open Sans or similar)
  - Size: 11pt
  - Color: Dark Gray (#333333)
  - Weight: Regular
  - Line spacing: 1.5
  - Paragraph spacing: 8pt

- Bulleted Lists:
  - Bullet style: Custom bullet using Warm Brown (#a57c52) circle
  - Indentation: 0.25" from left margin
  - Line spacing: Same as body text (1.5)

- Pull Quotes:
  - Font: Serif font (Garamond or similar), italic
  - Size: 14pt
  - Color: Deep Blue (#052d3f)
  - Weight: Regular
  - Background: None
  - Border: Left border only, 3pt, Warm Brown (#a57c52)
  - Padding: 0.5" left and right, 0.25" top and bottom
  - Margin: 0.5" from surrounding elements

## Special Elements

### Tip Boxes
```
+-------------------------------------+
|                                     |
|  TIP:                               |
|                                     |
|  Tip content goes here...           |
|  Multiple lines if needed.          |
|                                     |
+-------------------------------------+
```
- Background: Ultra-Pale Gray (#f8f8f8)
- Border: 1pt Warm Brown (#a57c52)
- Border radius: 5pt
- Padding: 0.5" on all sides
- "TIP:" label in Deep Blue (#052d3f), bold
- Content text same as body text

### Section Dividers
- Warm Brown (#a57c52) horizontal rule
- 1pt thickness
- 2" width
- Centered on page
- 24pt space above and below

### Conversation Guide Layout
Each question in a separate box:
```
+-------------------------------------+
| What routines or activities give    |
| you the most peace right now?       |
+-------------------------------------+
```
- Light background: Ultra-Pale Gray (#f8f8f8)
- No border
- Slight shadow effect
- 12pt padding
- 8pt space between question boxes

### Practical Checklist Layout
```
+-------------------------------------+
|                                     |
|  [ICON]  Everyday Essentials        |
|                                     |
|  What to Do:                        |
|                                     |
|  ✓ Create a shared calendar...      |
|  ✓ Compile a simple contact...      |
|  ✓ Walk through household...        |
|                                     |
|  Tip: Trust is key...               |
|                                     |
+-------------------------------------+
```
- Category title in Deep Blue (#052d3f), bold, 16pt
- Icon placed before category title, Deep Blue (#052d3f)
- "What to Do:" in Deep Blue (#052d3f), bold, 12pt
- Checklist items with Warm Brown (#a57c52) check marks
- Tip box as described above, but 90% width
- 24pt space between categories
